# 网页排版编辑器

一个本地优先的自用图片排版工具。页面各自保存布局，并共用同一份美术资产库。

## 启动

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 使用

1. 在左侧新建或切换页面。
2. 在右侧上传 PNG、WebP、GIF 或 JPG 图片；点击缩略图将素材放入当前画布。
3. 拖动图片移动，右下角控制点缩放，上方圆点旋转。
4. 在底部图层中拖动调整层级；可隐藏、锁定或删除画布元素。
5. 自动保存会写入当前浏览器的本地数据。可通过“导出”创建完整 ZIP 备份，再通过“导入”恢复为新项目。

删除画布中的元素不会删除资产库原图。多个同浏览器窗口会在保存后收到最新项目更新；这不是跨设备同步。清除浏览器站点数据前，请先导出项目备份。
