# 自用网页排版编辑器设计

## 目标

构建一个本地运行的网页排版编辑器。用户可创建多个独立页面，在同一份共享美术资产库中取用透明图片，并直接在画布上拖动、缩放、旋转素材。界面以画布为中心，不提供坐标输入或复杂属性面板。

## 范围

编辑器支持：

- 新建、重命名、切换和删除页面；每个页面有独立画布元素和图层顺序。
- 上传 PNG、WebP、GIF 等浏览器可读取的透明图片；上传的素材进入项目级资产库，点击缩略图可添加到当前页面。
- 在画布上选择元素后，通过拖动移动、控制点等比缩放、旋转手柄旋转。
- 图层面板拖放排序，以及元素的显示、隐藏、锁定、删除和撤销/重做。
- 自动保存、当前页面预览、完整项目的导入与导出。
- 同一浏览器、同一设备中打开多个窗口时，修改自动广播到其他窗口。

不包含：协作账号、跨设备云同步、文字编辑工具、矢量绘制、滤镜、复杂对齐面板或坐标输入。

## 技术边界

使用 Vite、React 和 TypeScript 构建单页应用。页面状态与图片二进制数据写入 IndexedDB；`BroadcastChannel` 用于通知同源窗口重新读取最新项目。项目导出为 ZIP，其中包含 `project.json` 和 `assets/` 图片文件；导入 ZIP 可恢复一个完整项目。

这是一份本机浏览器数据：清除浏览器站点数据会清除本地项目，因此导出是用户备份方式。多窗口同步适用于同一浏览器配置文件，不等同于跨设备同步。

## 数据模型

`Project` 包含项目标识、名称、当前页面 ID、页面列表和资产列表。

`Page` 包含页面标识、名称、画布宽高与元素列表。元素只引用资产 ID，因此删除画布元素不会删除资产库文件。

`CanvasElement` 包含元素标识、资产 ID、x/y、scale、rotation、visible、locked 和排序索引。页面中的元素按排序索引绘制，末尾元素位于最上层。

`Asset` 包含资产标识、原始文件名、MIME 类型、尺寸和 IndexedDB 中的 Blob。缩略图由浏览器从 Blob 生成，不额外改变原图片。

历史记录只储存布局操作的可序列化快照，不复制图片 Blob。单页最多保留 50 个撤销步骤。

## 交互设计

顶部栏显示项目名、撤销、重做、预览、导入和导出。左侧是页面列表；中间是画布；右侧是资产库；下方是当前页面图层。窄屏时侧栏折叠为抽屉，画布仍保持主区域。

首次启动时创建“未命名项目”和“首页”。创建页面后立即进入重命名，切换页面前先将当前状态写入本地。删除页面前要求确认；最后一个页面不可删除。

点击资产缩略图后，将一个默认尺寸的新元素放在画布可见中心并选中。未锁定元素可拖动；选中元素显示四个缩放角点及一个旋转手柄；隐藏元素不在画布显示且不能选中；锁定元素仍可显示，但不能被选中或修改。选中元素的 Delete/Backspace 删除该画布引用，绝不删除资产。

图层面板按顶部到低部的视觉顺序列出元素。拖放图层行会更新层级和画布显示顺序。眼睛按钮切换显示，锁按钮切换锁定，删除按钮删除元素。

所有持久化修改以短延迟自动保存。保存完成后通过 BroadcastChannel 发布项目版本；其他窗口收到通知后重读项目。若另一个窗口正在拖动元素，拖动结束后以最新已保存状态为准，避免持续互相覆盖。

预览以全屏覆盖层打开当前页面，只渲染画布，不显示选中框、控制柄和编辑面板。Esc 或关闭按钮返回编辑。

## 导入与导出

导出生成 ZIP：`project.json` 保存页面、元素及资产元数据，`assets/` 保存每个资产 Blob。导入前检查 ZIP 结构、图片 MIME 类型和项目版本。导入成功后建立一个新项目，不覆盖已存在的本地项目；新项目成为当前项目。

## 错误处理

当图片无法解码、导入包结构无效、写入空间不足或浏览器不支持 IndexedDB 时，显示可关闭的明确提示且保留当前内存状态。导出失败不影响已有项目。导入失败不创建半成品项目。

## 验证

测试核心状态转换：页面创建与切换、元素删除不影响资产、图层排序、撤销/重做和导入导出的项目结构。浏览器端检查包括上传透明图片、画布变换、双窗口自动同步、预览隔离和导入已导出的 ZIP。

## 启动

项目只需安装依赖后运行 `npm run dev`。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。
